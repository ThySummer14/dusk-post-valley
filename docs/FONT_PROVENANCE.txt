This project removes unused glyphs to keep the prototype small. It preserves the font's copyright and license fields. The original font is not this game's artwork.
The bundled package copyright file and the upstream Sans license contain the general Reserved Font Name definition and conditions, but no explicit Reserved Font Name designation was found for this source. The font's embedded name table likewise carries no RFN statement. Font family names were therefore not changed merely because of the generic OFL clause.
The complete package copyright/license is retained in assets/FONT_LICENSE.txt in the source package and FONT_LICENSE.txt in the standalone Web archive.
